I MIEI TURNI — PWA

Questa cartella contiene una versione installabile come web app:
- salvataggio locale sul dispositivo (localStorage)
- funzionamento offline dopo il primo caricamento
- calendario mensile
- colori per tutti i tipi di giornata
- cambio turno senza mostrare il turno precedente
- riepilogo mensile
- note personali

Per usarla come app su iPhone/iPad:
1. I file devono essere pubblicati su un sito HTTPS.
2. Apri l'indirizzo con Safari.
3. Tocca Condividi -> Aggiungi alla schermata Home.
4. Apri l'icona dalla Home.

NOTA: i dati sono salvati solo sul dispositivo/browser. Se cancelli i dati del sito, puoi perderli. Una funzione di backup/ripristino può essere aggiunta in una versione successiva.
